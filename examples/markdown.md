# Footnotes and alerts

A short explanation can carry a longer note.[^detail] Repeated references share
the same footnote.[^detail] Named labels work too.[^source]

> [!NOTE]
> Notes add context to the surrounding text.

> [!TIP]
> Hover over a footnote number to preview its text. Click the preview to read the
> complete footnote below, including its links and formatting.

> [!IMPORTANT]
> Keyboard users can focus a footnote reference to open its preview, press Enter
> to follow it, and press Escape to dismiss the preview.

> [!WARNING]
> Check the configuration before building a public site.

> [!CAUTION]
> Keep a copy of source files before making destructive changes.

[^detail]: This footnote contains **formatted text** and `inline code`.

    A second paragraph gives the longer explanation.

[^source]: Read the [project documentation](https://github.com/physbuzz/md2html)
    for configuration and command examples.
